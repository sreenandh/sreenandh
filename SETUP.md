# Put this on your GitHub profile

1. Open your public profile repository, `sreenandh/sreenandh`.
2. Replace its root `README.md` with the `README.md` in this package.
3. Upload the entire `assets` folder to the same repository, alongside `README.md`. Keep the filenames unchanged.
4. Commit the changes and open your GitHub profile.

The animation is a local GIF, so it does not depend on a typing-banner service, a statistics service or a scheduled GitHub Action. No token, workflow or API key is needed.

The README includes a narrower banner for mobile screens and static versions for browsers that honour the reduced-motion preference. Upload all four files in the assets folder.

The `SETUP.md` file and `tools` folder are optional and do not need to be uploaded to GitHub. The tools folder contains the original banner generator, which requires Python and Pillow if you later want to change the animation. Its default fonts are the DejaVu fonts commonly available on Linux; pass `PROFILE_FONT_DIR` if they are stored elsewhere.
